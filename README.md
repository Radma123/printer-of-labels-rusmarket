# Этикетки CNH — печать на TSC TE200

Локальное веб-приложение: по каталожному номеру находит деталь в CSV-каталоге
запчастей и печатает этикетку 100×72 мм на термопринтере TSC TE200 напрямую
языком TSPL (raw через CUPS), без стороннего софта для этикеток.

## Что нужно

* macOS с системным Python 3 (Pillow ставится автоматически в `.venv`);
* принтер TSC TE200, подключённый как очередь CUPS `TSC_TE200`,
  откалиброванный на рулон 100 мм (поперёк головки) × 72 мм (вдоль подачи),
  Media Sensor = GAP, зазор 3 мм;
* CSV-каталог запчастей в корне проекта (в git не хранится — большой).
  Разделитель `;`, каталожный номер в первой колонке. Индекс `.pnidx`
  для быстрого поиска собирается кнопкой в приложении (~2 минуты).

## Запуск

```bash
bash scripts/launch.sh          # запустить (обновление из git + сервер + браузер)
bash scripts/launch.sh status   # состояние и версия
bash scripts/launch.sh stop     # остановить
bash scripts/launch.sh restart  # перезапустить
```

Сервер поднимается на `http://127.0.0.1:8765/`, лог — `logs/app.log`.

Приложение-обёртка для запуска в один клик из Dock:

```bash
bash scripts/build_app.sh
```

Есть и CLI без веб-интерфейса:

```bash
python3 tsc_label.py --check                            # диагностика окружения
python3 tsc_label.py --demo --printer TSC_TE200         # тестовая печать
python3 tsc_label.py --pn НОМЕР --printer TSC_TE200     # печать детали
python3 tsc_label.py --pn НОМЕР --preview out.png       # превью без печати
```

## Структура

| Путь | Что |
| --- | --- |
| `label_app/catalog.py` | поиск по CSV: индекс «номер → смещение» + двоичный поиск по mmap |
| `label_app/layout.py` | геометрия этикетки в мм (единственный источник координат) |
| `label_app/render.py` | отрисовка Pillow и сборка задания TSPL |
| `label_app/barcode.py` | Code 128 |
| `label_app/translate.py` | перевод наименований, кэш в `translation_cache.json` |
| `label_app/server.py` | локальный HTTP-сервер и API |
| `label_app/static/` | веб-интерфейс (превью на CSS в тех же мм) |
| `tsc_label.py` | автономный CLI |

Тестов и CI нет — проверка через `--preview` и физическую печать.

## Логотипы

`label_app/static/logos/` содержит знаки правообладателей (CNH Genuine Parts,
FSC). Они используются в макете этикетки конкретного поставщика; при
использовании кода для других целей их нужно заменить своими.
