# Changelog

Формат: дата — что изменилось и зачем. Мелкие правки без значимых
последствий сюда не пишутся (см. `docs/decisions.md` для деталей и причин).

## 02.09.2026

- **Проект переехал** из `~/Downloads/` в `~/Documents/printer-of-labels-rusmarket`.
  Справочные материалы (руководство TSC в PDF, фото калибровки, макеты
  `labels_png/`) убраны в `reference/` и в git не попадают; артефакты
  прошлых прогонов (`_test_output/`, `rich_preview.png`) отправлены в Корзину.
- **Проект заведён в git** (ветка `main`, приватный репозиторий). CSV 1.14 ГБ
  и индекс `.pnidx` вне репозитория — GitHub не принимает файлы >100 МБ.
- **Запуск одним кликом:** `scripts/build_app.sh` собирает «Этикетки CNH.app»,
  которое дёргает `scripts/launch.sh` — обновление из git, `.venv` с Pillow,
  старт сервера, открытие браузера. Подробности в `docs/deploy.md`.
- **Исправлен молчаливый баг поиска в веб-приложении.** У CSV есть UTF-8 BOM
  (3 байта). Лежавший на диске `.pnidx` был собран без его учёта, все смещения
  были сдвинуты на 3 байта, и `/api/part` по любому номеру возвращал мусор
  (`"pn": ")"`), не выдавая ошибки. CLI `tsc_label.py` не задет — он читает
  CSV перебором, без индекса. Индекс пересобран (4 секунды), а в
  `catalog.index_is_fresh()` добавлена проверка `index_is_valid()`: первая
  запись индекса обязана указывать ровно на начало своей строки, иначе
  индекс считается несобранным. Проверено на реальных номерах C5NNF892A,
  1-32-574-086, V47456 — и напрямую, и через HTTP.

## 31.08.2026

- **Калибровка принтера TSC TE200 под этикетки 100×72 мм.** Через TSC
  Diagnostic Tool (Windows-ВМ) выставлены и подтверждены Get-запросом:
  Paper Width 100 мм, Paper Height 72 мм, Media Sensor GAP, Gap 3 мм,
  Speed 4, Density 8, Ribbon ON. Настройки хранятся в памяти самого
  принтера, не зависят от ВМ.
- **Принтер подключён к macOS напрямую** (отсоединён от Windows-ВМ),
  установлен MAC driver TSC-1.29, добавлена очередь CUPS `TSC_TE200`.
- **Написан `tsc_label.py`** — печать этикеток 100×72 мм из каталога
  CNH (CSV, 1.14 ГБ) напрямую командами TSPL через `lp -o raw`, без
  BarTender. Кириллица — рендер картинкой (BITMAP), штрихкод/QR —
  нативные команды принтера. Потоковый поиск по CSV без БД (~2.8 сек
  худший случай на полный файл).
- **Исправлен баг**: `queues()`/`send_cups()` не находили существующую
  печатную очередь `TSC_TE200`, потому что `lpstat -p` на русской
  локали macOS выводит «принтер X свободен» вместо английского «printer
  X is idle», а парсер искал только английский префикс. Исправлено
  форсированием `LC_ALL=C, LANG=C` для этих вызовов (константа
  `_CUPS_ENV`).
- **Расширены запасные пути к шрифтам** (`FONT_CANDIDATES`) и добавлена
  graceful-диагностика через `--check` — раньше отсутствие Pillow или
  подходящего TTF-шрифта могло привести к непонятной ошибке при запуске.
- Создан `docs/` handoff (этот набор файлов) — проект не в git, история
  до этой даты восстановлена по переписке, не по коммитам.

- **Подтверждено пользователем**: после патча локали печать через
  `TSC_TE200` работает «идеально» — базовый путь CSV → превью → TSPL →
  CUPS → физическая этикетка закрыт и рабочий.

**Открыто на конец дня**: нужен ли пакетный режим печати (список
номеров за один запуск) — обсуждалось как цель, но не уточнялось и не
реализовано. См. `docs/current-state.md`.
