## Три решения, вокруг которых построен весь проект

**1. Превью — это и есть то, что печатается.**
Браузер не верстает этикетку. Он показывает PNG, который нарисовал `render.py`
в 203 dpi, и поворачивает его средствами CSS (поворот кратен 90°, значит
ни один пиксель не искажён). Поверх лежат прозрачные рамки для перетаскивания.
Расхождение превью и печати структурно невозможно.
Цена — round-trip на сервер при каждом движении мыши. Подробности: [03](03-layout-render-tspl-2026-09-05.md), [05](05-frontend-2026-09-05.md).

**2. Все координаты в одном файле, в одних единицах.**
`layout.py` — только числа, ни строки логики. Миллиметры — единственная валюта:
CSS-пиксели из макета делятся на `PX_PER_MM` сразу, точки принтера появляются
только в `Canvas`. Поворот портрет→ландшафт делается один раз, в самом конце.
Подробности: [03](03-layout-render-tspl-2026-09-05.md).

**3. Ноль зависимостей, кроме Pillow.**
Ни фреймворка на сервере, ни npm на фронте, ни библиотеки штрихкодов, ни БД.
Каждое «не взяли» объяснено в соответствующем файле — не из принципа,
а потому что приложение ставится на рабочий Mac скриптом, и каждая
зависимость — это шанс, что установка не пройдёт.

## Что подмечено по ходу разбора

Разбор — не аудит, но несколько конкретных вещей всплыли при чтении.
Ничего критичного; перечислено по убыванию практической значимости.

**Производительность рендера.** `Canvas.font()` вызывает `ImageFont.truetype()`
при каждом обращении, а `tracked()` делает это **на каждый символ** — плюс
столько же в `tracked_width`. Для шести строк наименования это сотни загрузок
файла шрифта на один рендер. Лечится `lru_cache` на 5 строк — код и замер
в [03, Блок 6](03-layout-render-tspl-2026-09-05.md).

**Мёртвый код.** `_logo_path` в `render.py` определена дважды — строки 175 и 247,
тела идентичны. Побеждает вторая. Сейчас безобидно, но при правке одной копии
вторая молча выиграет.

**Неравномерная обработка ошибок в API.** В `do_POST` разбор JSON обёрнут
в `try` (`server.py:212`, `238`), а в `/api/preview.png` — нет
(`server.py:191`): `json.loads` и `int()` там могут бросить, и браузер получит
оборванный ответ вместо ошибки. Ручка вызывается только своим фронтендом,
так что на практике не стреляет.

**Временный файл в `build_app.sh`.** `SRC="$(mktemp -t label_launcher).applescript"` —
`mktemp` создаёт один файл, а используется другой (с добавленным расширением).
Созданный `mktemp`-ом остаётся сиротой во временной папке. Плюс `rm -f` в конце
не отработает, если `osacompile` упадёт (`set -e`). Корректный вариант через
`mktemp -d` + `trap` — в [06, Блок 11](06-cli-scripts-2026-09-05.md).

**Проверка пути в `serve_static`.** `path.startswith(STATIC)` без завершающего
разделителя пропустит соседнюю папку с общим префиксом, а `normpath` (в отличие
от `realpath`) не разрешает симлинки. Недостижимо на однопользовательской машине
с сервером на loopback; правильная форма через `realpath` + `commonpath` —
в [04, Блок 6](04-server-translate-2026-09-05.md).

**Нет проверки заголовка `Host`.** Единственный реальный вектор против
локального сервера без аутентификации — DNS rebinding. Три строки в `Handler`
закрывают его. Для внутреннего инструмента на изолированной машине — уместный,
но не обязательный шаг. Разбор в [04, Концепт 4](04-server-translate-2026-09-05.md).

**Дублированная формула поворота.** `screenToDesign` (`app.js:386`) и обработчик
стрелок (`app.js:724`) содержат одну и ту же матрицу обратного поворота.
Правка потребует помнить про оба места.

**`column()` ищет колонку по подстроке.** Возвращается первое совпадение
в порядке колонок файла. Если в следующей выгрузке каталога появится колонка
вроде `replaced_part_number` левее `part_number`, маппинг молча съедет.
Устойчивый вариант через regex по содержимому скобок — в [01, Блок 6](01-catalog-index-2026-09-05.md).

**Приватность перевода.** Наименования деталей уходят в MyMemory, который
в бесплатном режиме добавляет переводы в свою **публичную** память переводов.
Для номенклатуры запчастей это, скорее всего, безразлично — но решение
стоит принимать осознанно. Разбор в [04, Концепт 3](04-server-translate-2026-09-05.md).

**Логи растут без ротации.** `logs/app.log` никто не подрезает. Именно поэтому
`Handler.log_message` отключён целиком — иначе файл рос бы на десятки мегабайт
в день при дебаунсе превью.

## Быстрые проверки

Каждый файл разбора заканчивается разделом «Next Steps» с командами. Самые полезные:

Диагностика окружения (работает, даже когда сломано):

```bash
.venv/bin/python3 tsc_label.py --check
```

Проверить таблицу Code 128 на опечатки:

```bash
.venv/bin/python3 -c "import sys; sys.path.insert(0,'label_app'); import barcode as b; assert len(b._PATTERNS)==107; assert all(sum(map(int,p))==11 for p in b._PATTERNS[:106]); print('таблица в порядке')"
```

Отрендерить демо-этикетку в 4× и посмотреть глазами:

```bash
.venv/bin/python3 label_app/render.py
```

Замерить время рендера превью с шестью строками:

```bash
.venv/bin/python3 -c "import sys,time; sys.path.insert(0,'label_app'); import render; d={'lines':['OIL FILTER','FILTRO OLIO','FILTRE À HUILE','ÖLFILTER','FILTRO DE ACEITE','FILTRO DE ÓLEO'],'pn':'84565867','barcode':'84565867'}; t=time.perf_counter(); render.render(d,scale=4); print('%.2f c'%(time.perf_counter()-t))"
```

Прогнать shell-скрипты через линтер:

```bash
shellcheck scripts/launch.sh scripts/build_app.sh
```
