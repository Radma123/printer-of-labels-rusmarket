## Что это за проект (коротко)

Python-скрипт `tsc_label.py`, который берёт деталь из CSV-каталога
запчастей (`CNH_All_Parts_not-Full_20Cols.csv`) по каталожному номеру и
печатает этикетку 100×72 мм на термопринтере TSC TE200 напрямую языком
TSPL (raw через CUPS), без стороннего софта.

## Быстрый старт

```
cd ~/Downloads/printer-of-labels-rusmarket
python3 tsc_label.py --check                              # проверить окружение
python3 tsc_label.py --demo --printer TSC_TE200            # тестовая печать
python3 tsc_label.py --pn C5NNF892A --printer TSC_TE200    # печать реальной детали
```

Тестов и CI нет. Проверка — только вручную: `--preview`, затем физическая
печать. Подробности и текущий незакрытый шаг — в `docs/current-state.md`.

## Запуск и обновление

Запуск на macOS одним кликом, авто-обновление через закрытый git-репозиторий
и установка на новую машину — см. **`docs/deploy.md`**.
Важно: CSV (1.14 ГБ) и `.pnidx` в git не хранятся, переносятся вручную.
